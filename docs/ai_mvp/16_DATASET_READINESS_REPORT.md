## What this proves

- YOLO structure is internally readable: no missing labels, invalid class IDs or malformed rows in these three datasets.
- Empty label images exist and are counted as candidate hard negatives.
- The current `merged` dataset has no reported `bong_troc` instances even though `class_map.json` reserves class ID 2. It therefore cannot support a six-class MVP claim.
- These counts do **not** prove that images are concrete rural roads, that labels are correct, or that the model generalizes to drone video.

## Data decision

Use `merged`/15K only as a baseline/pretraining source. Before training a release candidate, add a versioned drone-domain dataset with road masks, real crack/pothole positives, and hard negatives from the four project surveys. Keep a survey-level holdout outside training.

## Tool contract

`audit_dataset_readiness.py` exits `0` for structural PASS and `2` for missing labels, invalid class IDs or malformed rows. A structural PASS is necessary but not sufficient for MVP acceptance.
